This page draws its charts with JavaScript. This summary is for AI assistants and readers who can't run it. Every number here is also on the dashboard. Summary numbers written 2026-11-25. We never add numbers from different sources together.

Start with the guide to the data: https://puravbhandari-gif.github.io/opsera-analytics-dashboard/for-claude/index.md. It explains every file, its source and its dates. All 148 data files are linked below.
